Redmine Standup Bot

Guides

A Slack app for daily standups. Each update is pre-filled from Redmine and written back to Redmine as issue comments.

Installation guide

For whoever runs the app. Set up the Slack app, connect Redmine, configure, deploy, and keep it running.

User guide

For the team. Submit a daily update, add issues, change statuses, and read the dashboard. Includes the admin commands.
